Acerca de Mastitrack

Mastitrack

v1.0.0

Universidad Nacional Rosario Castellanos

Proyecto universitario

Mastitrack es un sistema de monitoreo y deteccion temprana de mastitis bovina, desarrollado como parte del proyecto prototípico de cuarto semestre para la carrera de Ciencia de Datos para Negocios. Universidad Nacional Rosario Castellanos (UNRC).

El sistema integra registro de ordeño, está preparada para recibir datos de sensores de calidad de leche, evaluación de riesgo mediante redes neuronales y calculadora de impacto financiero para apoyar la toma de decisiones en pequeños y medianos establecimientos ganaderos.
